Agent Wills GitHub

When an agent dies, it leaves a will.

A tiny open-source plugin for Claude Code. When a session or subagent ends, it writes a few hundred tokens of will.md: what's done, what's unfinished, what to watch for. The next agent in that folder inherits it.

/plugin marketplace add VedSoni-dev/agent-wills
/plugin install agent-wills@agent-wills

Type these in Claude Code, then restart it. Needs Node 18+.

npm install -g github:VedSoni-dev/agent-wills
wills install

Adds three hooks to ~/.claude/settings.json (with a backup) and the wills command. Needs Node 18+.

Small on purpose

Plain markdown

One file per death in .claude/wills/, git-ignored by default. No database, no background service, no dependencies.

Exit is never held up

A plain will is written in milliseconds. The model rewrites it in the agent's voice in a detached process, after Claude Code has closed.

Subagents too

Every subagent leaves a short will in .claude/wills/subagents/. Ask for one in the agent's own words with /will.

Who writes the will

Secrets are redacted before anything is written or sent. If a model fails, the plain will stays.
